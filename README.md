# 🧠 ZenTask
### A Unified Productivity Environment for Students

> "Human productivity is often destroyed not by laziness, but by fragmented tools."

ZenTask is a modern productivity dashboard designed to consolidate tasks, schedules, notes, and focus tools into a single intelligent workspace.

Instead of juggling multiple applications for planning and studying, ZenTask provides a centralized productivity system designed specifically for students and deep work.

---

# 📚 Abstract

Students and knowledge workers often rely on multiple disconnected tools such as task managers, calendars, note-taking apps, and focus timers.

This fragmentation leads to context switching, reduced concentration, and inefficient workflows.

ZenTask proposes a unified solution by integrating:

- task management  
- scheduling tools  
- productivity timers  
- academic planning  

within a single platform.

The goal is simple: reduce friction between planning work and actually doing it.

# 🧩 Core Features

### 📋 Task Management
Create, organize, and track daily tasks with priority levels.

### 📅 Calendar & Event Scheduling
Plan academic deadlines, tasks, and exams in an integrated calendar view.

### ⏱ Focus Mode (Pomodoro Timer)
Structured work sessions designed to improve concentration.

25 minutes focus  
5 minute break  
repeat.

### 📝 Notes System
Capture study notes and ideas quickly inside the workspace.

### 📚 Study Planner
Plan academic schedules and exam preparation.

### 🔔 Notifications
Stay updated with reminders and alerts.

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/hydrakarthik/Zentask.git
```

Move into the project folder

```bash
cd Zentask
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open your browser and visit

```
http://localhost:3000
```

---

# 🔐 Environment Variables

Add the following environment variables:

```
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
```

Add them in:

```
Vercel → Project Settings → Environment Variables
```
